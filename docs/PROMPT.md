# PROMPT — TECHFIX OS

Atue como um desenvolvedor experiente em **React Native, Expo Snack, JavaScript e Supabase**, com foco em criar projetos acadêmicos simples, funcionais e fáceis de explicar.

Sua tarefa é desenvolver o projeto completo **TechFix OS**, criado pelos alunos **Roberto e Vinicius** para uma apresentação escolar.

## PRIORIDADES

Siga esta ordem de prioridade:

1. O aplicativo deve funcionar.
2. O código deve ser fácil de entender.
3. Todo o aplicativo deve caber em um único `App.js`.
4. Deve ser fácil copiar e executar no `snack.expo.dev`.
5. Deve cumprir todos os requisitos de CRUD da atividade.
6. A interface deve ser simples e visualmente agradável.
7. Evite qualquer arquitetura ou recurso desnecessário para um trabalho escolar.

Não transforme o projeto em uma aplicação profissional complexa.

---

# 1. CONTEXTO DO PROJETO

**Nome:** TechFix OS

**Nicho:** Assistência Técnica e Reparo de Celulares e Informática.

**Objetivo:** criar um aplicativo simples para controlar Ordens de Serviço (OS) de uma assistência técnica.

O sistema deverá registrar:

- modelo do aparelho;
- defeito relatado;
- custo da peça;
- valor da mão de obra;
- status do reparo;
- valor total calculado automaticamente.

**Público-alvo:** pequenas assistências técnicas e técnicos que precisam organizar aparelhos recebidos para reparo.

# 3. CONFIGURAÇÃO DO SUPABASE

No início do `App.js`, utilize:

```js
const SUPABASE_URL = 'COLE_SUA_URL_AQUI';
const SUPABASE_ANON_KEY = 'COLE_SUA_CHAVE_AQUI';

const supabase = createClient(
  SUPABASE_URL,
  SUPABASE_ANON_KEY
);
```

Importe corretamente:

```js
import { createClient } from '@supabase/supabase-js';
```

Para esta demonstração acadêmica no Snack, utilizar a chave pública `anon` ou publishable fornecida pelo Supabase.

Não implementar login ou autenticação.

---

# 4. BANCO DE DADOS

Criar no Supabase a tabela:

```text
ordens_servico
```

Campos obrigatórios:

```text
id
modelo_aparelho
defeito_relatado
custo_peca
valor_mao_de_obra
status_os
created_at
```

Utilize este SQL como base:

```sql
create table ordens_servico (
  id bigint generated by default as identity primary key,
  modelo_aparelho text not null,
  defeito_relatado text not null,
  custo_peca numeric default 0,
  valor_mao_de_obra numeric default 0,
  status_os text default 'Em Análise',
  created_at timestamp with time zone default now()
);

alter table ordens_servico disable row level security;
```

Não criar coluna `valor_total`.

O total deverá ser calculado no JavaScript:

```text
TOTAL = CUSTO DA PEÇA + MÃO DE OBRA
```

- estado temporário da interface.

- Modelo do aparelho;
- Defeito relatado;
- Custo da peça;
- Valor da mão de obra;
- Status.

Adicionar o botão:


1. validar os campos;
2. inserir a OS no Supabase;
3. mostrar mensagem de erro caso a operação falhe;
4. mostrar mensagem de sucesso se funcionar;
5. limpar o formulário;
6. recarregar a listagem.

Campos obrigatórios:

```text
modelo_aparelho
defeito_relatado
```


```text

```


- carregamento;

- exclusão.
